## What is KerbHUD

* **Read-only** overlay for **iRacing** and **Le Mans Ultimate**: transparent, always on top and **click-through** (the mouse goes to the game) and it **never steals focus**.
* The game must run in **borderless window** mode. In exclusive fullscreen Windows does not let anything appear on top.
* Just want to see how it looks? **Simulator → DEMO** shows test data (always flagged as DEMO).

## The main window

* **1 · Menus:** *Overlay* (edit mode, visible, always on top, quit), *Simulator* (automatic, iRacing, LMU, DEMO), *Config* (Settings, units), *Tools* (download logos and flags, open folders), *Window* and *Help*.
* **2 · Version bar:** shows the installed version and the **Check for updates** button, which becomes **Download and install** when a new version exists.
* **3 · Tabs:** **Widgets** (the modules) and **Layouts** (activate, rename, duplicate, export, import, delete).
* **4 · On/off** for each module. **5 · Config** opens that module's options (columns, range, reserve...), applied instantly. **6 ·** the selector sets when it appears (global rule, always, on track only, in the garage only).
* Closing the window with the **X does not quit**: the program stays in the **tray** (icon near the clock). Click the icon to reopen; **Overlay → Quit** really exits.

## Positioning modules (edit mode)

Turn **edit mode** on (hotkey below, or Overlay → Edit mode). Every module appears and becomes clickable:

* **Move:** drag the module.
* **Resize:** drag the edges or corners, or use the **mouse wheel** (keeps the proportion).
* **Opacity:** `Ctrl` + mouse wheel.
* **No grid snapping:** hold `Alt` while dragging.

Turn edit mode off to return to click-through. Everything is saved automatically in the active layout.

## When the overlay appears

* **Always:** all the time. **On track only / In the garage only:** only with the simulator connected and the driver really on track / in the garage. **DEMO mode is always shown.**
* Each module can follow the global rule or have its own (Widgets tab).
* While you use the taskbar, the tray or the Start menu, the overlay steps off "always on top" so it does not get in the way.

## Your data

* The **dados** folder, next to the program, holds logos, flags, badges, layouts and tracks. Updates never touch it.
* Logos and flags: **Tools → Download...** (internet) or copy the images into the folder.
* **Config → Settings:** language, refresh rates, my country, LMU rank, hotkeys and updates.

## Updates and what's new

* Enter the repository in **Settings → Update** and use **Help → Check for updates**.
* What's new appears here after every update. To read it again: **Help → User guide** and **Help → What's new**.
